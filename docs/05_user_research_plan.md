# User Research Plan

## Document control

**Status:** Skeleton.

**Owner:** Project lead.

## Research objectives

- Validate the current reimbursement workflow and its pain points.
- Validate the proposed pilot policy and human authority boundary.
- Identify an adverse effect, burden, or risk introduced by the prototype.
- Record one feedback-originated improvement with consent and traceable evidence.

## Interview guide

1. Ask the participant to describe the last reimbursement request they submitted or reviewed.
2. Ask which facts, checks, or handoffs create waiting, mistakes, or uncertainty.
3. Test representative routine and escalation cases against the proposed policy.
4. Ask whether the system result and escalation question are understandable and actionable.
5. Ask what could go wrong or add burden if the system were used.
6. Ask whether a quote, role, or screenshot may be used and record the consent outcome.
